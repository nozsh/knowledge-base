{{< callout type="info" >}}
Из длинной ссылки сделать короткую ссылку.
{{< /callout >}}

{{< callout type="info" >}}
Больше ресурсов на [fmhy](https://fmhy.net/internet-tools#url-shorteners?sl).
{{< /callout >}}

- [Emojied](https://emojied.net/?sl) и [🏹.to](https://xn--kn8h.to/?sl)
  - Ссылка из emoji.
- [is.gd](https://www.is.gd/?sl) <sup>🌟</sup> и [v.gd](https://v.gd/?sl) <sup>🌟</sup>
  - Старый и проверенный.
- [t.ly](https://t.ly/?sl)
- [Wiki Shortener](https://meta.wikimedia.org/wiki/Special:UrlShortener?sl)
  - Сокращатель для ссылок Wikipedia.
- [x.gd](https://x.gd/?sl)
- [zws](https://zws.im/?sl)
  - Нулевой символ.
  - Ссылка получается - `zws.im/`.
