{{< callout type="info" >}}
Поисковики по разным торрент сайтам.
{{< /callout >}}

{{< callout type="warning" >}}
Все торрент агрегаторы с низким уровнем доверием, потому что могут использовать источники как с высоким уровнем доверия, **так и с низким**.
{{< /callout >}}

<br>

- {{< icon "trust low" >}} [Bitsearch](https://bitsearch.to/?nt)
  - Продвинутая поисковая система, которая просто собирает метаданные торрентов, такие как названия файлов, их размеры и magnet-ссылки.
- {{< icon "trust low" >}} [BT4G](https://bt4gprx.com/?nt)
  - Поисковая система торрентов, использующая DHT, цель которой - упростить поиск и скачивание торрентов для всех.
- {{< icon "trust low" >}} [BTDigg](https://btdig.com/?nt)
  - Отличная поисковая система BitTorrent DHT, которая собирает метаданные и возвращает магнет ссылки, а не хранит материал.
- {{< icon "trust low" >}} [BTMET](https://btmet.com/?nt) <sup>(m)</sup>
  - Поисковая система магнет с возможностью предварительного просмотра, которая позволяет быстро начать скачивание практически всех медиафайлов.
- {{< icon "trust low" >}} [EXT Torrents](https://ext.to/?nt) <sup>(m)</sup>
  - Универсальная система поиска магнет ссылок для быстрого скачивания медиафайлов различных жанров.
- {{< icon "trust low" >}} [iDope](https://idope.se/?nt)
  - Анонимный поиск по большой коллекции. Пользователи не отслеживаются, а их IP-адреса удаляются.
- {{< icon "trust low" >}} [Knaben Database](https://knaben.eu/?nt)
- {{< icon "trust low" >}} [MagnetDL](https://www.magnetdl.com/?nt)
  - Софт, фильмы, игры, электронные книги, ТВ-шоу и музыка - все это распространяется через магнет ссылки.
- {{< icon "trust low" >}} [SolidTorrents](https://solidtorrents.to/?nt)
- {{< icon "trust low" >}} [Torrends](https://torrends.to/?nt)
